# 💊 مشروع MediStick (النظام الذكي لتوزيع الأدوية)

## 📌 نبذة عن المشروع
**MediStick** هو مشروع ابتكاري يهدف إلى تسهيل وتنظيم تناول الأدوية لمختلف الفئات (مثل كبار السن وذوي الاحتياجات الخاصة). يدمج المشروع بين الحلول الذكية، التصميم الهندسي، والتطبيقات التفاعلية لضمان الالتزام بالأوقات بدقة وسلامة.

---

## 🛠️ مراحل التطوير والعمل التقني

### 1. التصميم الهندسي والنمذجة ثلاثية الأبعاد (3D Modeling)
* تم تصميم الهيكل الخارجي وتقسيمات الأدوية بدقة (حسب الأيام والأوقات: صباحاً، ظهراً، مساءً، ليلاً) باستخدام برامج النمذجة الهندسية.
* إعداد الملفات وتجهيزها لعمليات **الطباعة ثلاثية الأبعاد (3D Printing / Slicing)** لإنتاج النموذج الأولي الفعلي.

### 2. المنصة التفاعلية والتطبيق المبدئي (Interactive Platform Prototype)
* تطوير واجهة ومنصة تفاعلية كنموذج مبدئي (Prototype) مرتبطة بنظام العدادات وتوزيع المواعيد، لتمكين المستخدم من متابعة الجرعات بطريقة مرئية وسهلة ومبسطة.
